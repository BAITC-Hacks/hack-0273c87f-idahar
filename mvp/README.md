# HackAlem AI MVP

Локальный прототип для кейса о геймификации бизнес-задач. Заказчик создаёт карточку, видит объяснимый рейтинг готовности, уточняет её с помощью ИИ и вручную выбирает предложения студенческих команд.

## Запуск

1. Открой `.env` и вставь ключ после `OPENAI_API_KEY=`. Не добавляй кавычки, не отправляй ключ в чат и не публикуй этот файл.
2. В PowerShell из папки `outputs` запусти `npm start` или `node server.mjs`.
3. Перейди на `http://127.0.0.1:4173`.

Нужен Node.js 20 или новее. Сервер слушает только `127.0.0.1`. Файл `.env` исключён из Git.

## Рейтинг готовности

Баллы даются только за непустые поля после явного подтверждения заказчиком. ИИ не назначает рейтинг.

| Поле | Баллы |
| --- | ---: |
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Связь с бизнесом | 10 |

Уровни: 0–39 — черновик; 40–69 — рабочая; 70–89 — готовая; 90–100 — приоритетная. Каталог сортируется по рейтингу, но низкий балл не скрывает задачу и не запрещает отклики.

## ИИ и предложения

OpenAI формирует три уточняющих вопроса, связанных с полями карточки. Формат ответа ограничен JSON Schema: ровно три вопроса и только по семи критериям. Ответы попадают в редактируемый черновик, а заказчик проверяет и подтверждает сведения перед публикацией. ИИ не добавляет факты и не выбирает команду. Статус в шапке показывает, запущен ли сервер и настроен ли API-ключ.

Студенты просматривают общий каталог и подают предложение с идеей, планом, сроком и ссылкой. Заказчик может выбрать несколько предложений, отклонить их или оставить все без выбора. В прототип добавлены пять синтетических профилей команд и пять примерных предложений.

## Сценарий демонстрации

1. Создать задачу с неполными сведениями и показать три вопроса OpenAI.
2. Добавить ответы, подтвердить сведения и показать изменение рейтинга и уровня.
3. Открыть общий каталог: черновики остаются видны, а готовые задачи выше в списке.
4. Выбрать команду, подать предложение и вручную принять, отклонить или оставить без выбора.
